# Bulk Exam Actions: clinic portal demo

A clickable product demo: a clinic Admin ticks exams on the Exams tab and turns them off, or back on, in one step, with the impact spelled out first, then undo and a change history.

**Open it:** https://sirbrentz.github.io/qualiphy-bulk-exams-demo/

- Plain HTML, CSS and JavaScript. No build step, no server, no network calls beyond Google Fonts.
- Fake data only. Not connected to any Qualiphy environment.
- Icons are the portal's react-icons glyphs (MIT); licences are listed in `icons.js`.
